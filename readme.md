## 📂 Portfolio Codebase Setup

To run and explore this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vs105/Portfolio.git
   cd Portfolio
   ```

2. **Open in browser:**
   - Double-click `index.html` or launch with VS Code **Live Server**.

3. **Project Structure:**
   ```text
   Portfolio/
   ├── index.html        # Main HTML structure with 9 sections

   ├── achievements/     # Certificate & achievement assets
   ```
